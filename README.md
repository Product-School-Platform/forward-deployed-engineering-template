# Marlow dossier

> My final project for Product School's **Forward Deployed Engineering** certification. One engagement, six files, then a practical on a case issued in the room.

This is a **template repo**. Click **Use this template → Create a new repository**, name it `marlow-dossier`, and commit one file per module.

The case lives in `marlow/`. Your work lives in the numbered folders. If a file is not committed here, it did not happen.

---

## What you commit

| Module | You write | File |
|---|---|---|
| 1 | Fit test | `01-fit/fit-test.md` |
| 2 | Workflow cut | `02-workflow/workflow-cut.md` |
| 3 | Access boundary | `03-access/access-boundary.md` |
| 4 | One trace | `04-thin-deployment/thin-deployment.md` |
| 5 | Rollout rung | `05-rollout/rollout-ladder.md` |
| 6 | Handover, then the practical | `06-handover/handover.md`, then `06-handover/practical.md` |

Each folder has a `LAB.md`. Paste it into your coding agent and tell it to walk one step at a time and stop at every decision. You can also edit the file on GitHub and commit in the browser.

## How to commit

On GitHub: open the file, edit it, and commit with the message in that file.

From a clone, which Module 4 needs:

```bash
git add 01-fit/fit-test.md
git commit -m "Score Marlow on the fit test."
git push
```
